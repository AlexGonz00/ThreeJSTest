# Basic Three.js Website
#### Developed using [Wael Yasmina's YT Tutorial](https://www.youtube.com/watch?v=xJAfLdUgdc4)

## Environment setup (for future Three.js projects)

### Install a bundler:

        npm init -y

You don't need to install a bundler, but it's good for future-proofing your project

### Install Parcel

        npm install parcel --save-dev

### Install Three.js

        npm install three

### To run locally, run:

        parcel ./src/index.html

Holds the distribution version of the project

### To deploy, push latest changes to main, then run:

        npm run deploy
